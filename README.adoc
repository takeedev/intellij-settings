== Setup

Close all IntelliJ IDEA processes before running the setup. Existing settings and
`~/.ideavimrc` are backed up to
`~/.intellij-settings-backups/<YYYYMMDD-HHMMSS>/` before installation.

Set `INTELLIJ_SETTINGS_BACKUP_DIR` to use a different backup directory.

=== Intellij-Community

[source,shell,subs="attributes"]
----
curl -s {raw_intellij_settings_url}/setup-ic.sh | /usr/bin/env sh
----

=== Intellij-Ultimate

[source,shell,subs="attributes"]
----
curl -s {raw_intellij_settings_url}/setup-ij.sh | /usr/bin/env sh
----
